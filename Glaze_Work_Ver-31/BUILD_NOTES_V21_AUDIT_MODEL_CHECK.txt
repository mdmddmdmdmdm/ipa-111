FIXES
1. Field status "On, but not found in the prompt" for Scenario / Dialogue Examples:
   false alarm (text with {{user}}/{{char}} could not be matched). character_field_switches.dart
2. Chat with NO preset sent only the card: no summary, memory, lorebooks, author's note, guidance.
   New lib/core/llm/built_in_default_preset.dart; prompt_builder.dart builds with it when no preset
   exists (bare fallback only if that build throws).
3. Summary: empty model reply no longer overwrites the saved summary (error shown instead);
   timeout at least 240 s (non-streaming call); transcript trimmed to fit the context. summary_service.dart
4. Role-template 400 ("roles must alternate", "Unable to generate parser"): retry strict, then
   single (one user message). Remembered per endpoint+model. post_processing_chat_transport.dart
   If it still fails the server's own template is the problem: start llama-server with a lenient
   --chat-template, or --no-jinja.
5. Blank API key allowed for Custom Chat Completion endpoints that are not known hosted providers
   (Ollama etc.). Hosted providers still need a key.
6. Built-in presets: strict layout, 240 s first-chunk timeout, stepped trim; existing built-in
   presets upgraded once (only values still at old defaults).

ROUND 2 ADDITIONS
- Preset flag "reasoningEnabled" is only the editor's "parse inline reasoning" switch; inline <think>
  tags are ALWAYS parsed. The app's own reasoning for a model without native reasoning is the
  Prompt Helper "Think First". It now follows the connection's Reasoning effort:
  min <40 words, low <80, medium/auto <150, high ~300, max ~500. (prompt_helpers.dart + 3 call sites)
  Use Think First when Request native reasoning is OFF; turn it off for models that reason natively.
- Ollama (port 11434 or host containing "ollama"), Custom Chat Completion, Request native reasoning
  OFF: the request now carries reasoning_effort = "none" so the model does not think and eat the reply
  budget. An Extra Request Parameter with the same key overrides it. (openai_chat_transport.dart)
- Reviewed, no change: all 10 bundled preset JSONs parse and contain a chat-history block; avatar
  vault + restore pass look correct (an image already lost and never vaulted cannot be recovered).

ROUND 3
