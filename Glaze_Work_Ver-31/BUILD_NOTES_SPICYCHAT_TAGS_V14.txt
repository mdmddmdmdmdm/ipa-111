SpicyChat full tag vocabulary (v14)

Problem
-------
The SpicyChat filter sheet only showed a short curated set of tags
(Dominant, English, Fantasy, Female, FemalePOV, LGBTQ+, Male, MalePOV,
NSFW, Romantic) while the live site "Narrow by tag" panel exposes the
full vocabulary (Anime, Furry, Yandere, CNC, Omegaverse, Non-Human, …).

Root cause
----------
fetchSpicyChatTags() relied solely on the public Typesense `tags` facet.
The scoped search key applies facet sampling (facet_sample_percent ≈ 10),
so the facet often returned only the most popular names. The UI then
rendered that incomplete list.

Changes
-------
lib/features/catalog/services/spicychat_provider.dart

1. Seed the tag list with a comprehensive static vocabulary taken from the
   live SpicyChat "Narrow by tag" panel (NSFW, Female, Male, MalePOV,
   Dominant, FemalePOV, Romantic, Submissive, LGBTQ+, English, Fantasy,
   Gentle Dom, Original Character, Scenario, Anime, Size Difference,
   Multiple Characters, Anal, Drama, Mature, Adventure, Corruption,
   Horror, Action, Friend, Anthro, Wholesome, Sadistic, MILF, Furry,
   Age Play, Oral, Low Quality, Partner, Bondage, MLM, Cheating,
   Fictional Media, Magic, Muscle, Gothic, Impregnation, Monster,
   Comedy, Game, Married Partner, Villain, Yandere, Chubby, Roommate,
   Masochistic, Smell, Futanari, CNC, Switch, Supernatural, Sci-Fi, RPG,
   Tsundere, Fat, Real, NTR, Femboy, Giant, Hero, Slave, Mind Control,
   Feet, Tomboy, Non-English, Lactation, WLW, Transformation, Vore,
   Servant, Mythological, Omegaverse, Trans, Pregnant, Mystery,
   Historical, Crossdressing, Non-Binary, Flatulence, Inflation,
   Simulator, Watersport, AI Assistant, Nature, Inanimate, Non-Human,
   AnyPOV, …).

2. Still query Typesense (facet_limit / max_facet_values raised to 1000,
   exhaustive strategy) and merge any extra names the facet returns,
   preferring the exact casing Typesense supplies.

3. _canonicalSpicyChatTag() also consults the static seed and a few
   common aliases (Non-Human, FemalePOV, MalePOV, AnyPOV, LGBTQ+, Sci-Fi)
   so filters remain correct even before the first network fetch.

Result
------
The SpicyChat filter sheet now shows the full tag set that appears on
https://spicychat.ai (with NSFW still controlled by the dedicated
"Show NSFW" toggle). Selecting a tag continues to emit the exact
Typesense filter `tags:=ExactName`.

Previous path fixes (favorite-bots / recommended-bots) from v13 are
retained in this archive.
