SpicyChat Favorites + Recommended path fix (v13)

Problem
-------
SpicyChat Favorites tab showed "0 results / No characters found" even when
signed in. The For You (recommended) feed was also hitting a dead path.

Root cause: SpicyChat moved the authenticated account feeds:

  old (broken in app)          new (live site)
  --------------------         ---------------
  /favorites                   /favorite-bots
  /recommendations             /recommended-bots

The headless scraper was still loading the old URLs, which return an empty
or login-walled page, so the DOM scraper found zero cards.

Changes
-------
1. lib/features/catalog/services/unified_favorites_service.dart
   - spicyChatWebFeed path for the combined Favorites grid:
     '/favorites' → '/favorite-bots'

2. lib/features/catalog/catalog_provider.dart
   - Provider-scoped Favorites fetch: '/favorites' → '/favorite-bots'
   - For You / recommended sort: '/recommendations' → '/recommended-bots'
   - (Recent still uses '/chats'; unchanged)

The scraper itself (link patterns /chatbot/ and /character/, scroll + extract)
was already resilient and needs no change once the correct page is loaded.

Chub presets in Favorites
-------------------------
Chub account favorites continue to be pulled via the existing
api.chub.ai/api/favorites endpoint (characters + any preset-like nodes the
API returns). No path change was required on the Chub side; the cards that
appear with the "CHUB / mobile" tags are the ones the account has favorited.

Image crop / zoom / rotate on avatar
------------------------------------
Optional request noted. Current avatar picker still does a direct FilePicker
→ save. A full crop/rotate UI would need a new interactive editor (image
package + InteractiveViewer or an added dependency). Left out of this
source drop so the critical SpicyChat feed fix ships cleanly; can be added
in a follow-up if desired.

Build note: Flutter/Dart/Xcode are not installed in this environment. This
archive is source-only.
