1. CHARACTER IMAGE "Couldn't load the image"
   No code path in the repo deletes avatar files, so the exact trigger could not
   be proven statically. The failure shows when the full-size file
   avatars/<id>.png is missing/empty while its row still points at it. Fixes:
   - platform_paths.dart: new resolveGlazeDisplayPath(). If the full image is
     missing it (a) tries the same id with another extension, then (b) copies
     thumbnails/<id>.* back to avatars/<id>.png. resolveGlazeThumbnailPath()
     falls back to it. Used by the character detail hero, the full-screen
     viewer, the chat header and chat stats sheet.
   - image_storage_service.dart saveAvatar(): flush + verify the file exists
     and is non-empty before the path is stored (throws otherwise, so the
     editor's existing error dialog shows instead of saving a dead path).
   - sync_binary_asset_syncer.dart sanitizeInvalidAvatarPath(): restores the
     avatar from its thumbnail instead of nulling avatarPath when possible.

2. REASONING
   - Claude "Auto" never produced reasoning (thinking config was omitted).
     On adaptive-thinking models Auto now sends thinking:{type:"adaptive"}
     with no effort, so the model decides. Non-adaptive Claude + Auto still
     omits thinking (those models require an explicit budget).
   - isAdaptiveClaudeModel() now covers Sonnet 4.6+, Opus/Sonnet/Haiku 5.x,
     Fable and Mythos ids (previously Opus only), and no longer mis-detects
     dated ids like claude-opus-4-20250514.
   - Adaptive thinking now also drops temperature/top_p/top_k (thinking rejects
     custom sampling, same as the budget path).
   - Gemini: thinking config was skipped for ids like models/gemini-2.5-pro or
     gemini-flash-latest because the match was anchored with ^. Fixed.
   - Official OpenAI reasoning families (o-series, GPT-5+): send
     max_completion_tokens instead of max_tokens (max_tokens is rejected).
   - UI hint for "Auto" (en.json) now says the AI decides.

3. KNOWN / NOT CHANGED
   - Official OpenAI reasoning models also reject non-default temperature/top_p;
     use the "include" toggles to switch those off for such models.
   - ru.json hint for Auto left as is.

4. LOCAL MODELS (KoboldCpp / LM Studio / llama.cpp / Ollama on a PC)
   Audited the Custom Chat Completion path for local servers. Defaults are safe
   (no cache_control, no session_id, reasoning off unless enabled, "Auto" sends
   no reasoning_effort, <think> tags and reasoning_content are parsed).
   - iOS Info.plist: added NSLocalNetworkUsageDescription. Without it iOS never
     shows the Local Network prompt, so http://<PC-LAN-IP>:port silently fails.
     If it was previously denied/never asked: iOS Settings > Glaze > Local Network.
   - Android network_security_config.xml: cleartext HTTP allowed (was only
     localhost), so http://192.168.x.x endpoints connect. Trade-off: HTTP is
     no longer blocked app-wide on Android; remove <base-config> to revert.
   - min_p / repetition_penalty are not first-class sliders. Add them under
     Extra Request Parameters (e.g. min_p = 0.05, repeat_penalty = 1.1); they
     are sent as-is.
   - Non-thinking finetunes (RPMax, Cydonia, Mag-Mell, Magnum, Darkest Planet,
     Grand Horror): leave Request Reasoning OFF or effort on Auto.
