Glaze v29: Provider Characters tab, impersonation fix, stronger User Agency
============================================================================
Not compiled (no Flutter SDK here). Run: flutter analyze && flutter test
New tests: test/provider_chats_test.dart, test/user_agency_enforcement_test.dart,
group 'PromptHelpers impersonation' in test/prompt_helpers_test.dart.

1. Provider Characters (3rd tab in Characters: "Providers"; header reads "Provider Characters")
   - Lists the characters the signed-in JanitorAI / SpicyChat / Chub / CrushOn accounts have
     chatted with. Chips: All, or one account. Search box filters by name / last message.
   - Tap a chat: read-only viewer (no composer, nothing is sent to the provider), shows the
     provider's memory, Export (SillyTavern .jsonl) and "Import & continue".
   - Import: reuses the app's chat import. Messages arrive in order with replies' alternates
     as swipes, so the story is exactly where it was; the provider's memory becomes the chat
     summary. The character is matched to one already in the library (by source link, or by
     name after asking); otherwise the normal character import opens first; for an exported
     file you pick the character.
   - "Open exported chat": reads a .jsonl / .json / .txt export read-only, then the same
     Export / Import.
   - Reads go through each site's own signed-in session. JanitorAI uses /hampter/chats (the
     endpoint family the app already uses). SpicyChat, Chub and CrushOn do not publish a chat
     API: addresses are best guesses; if none answers, the tab shows every address it tried
     with the status, so a screenshot is enough to fix it.
   Files: features/catalog/provider_chats/*, features/character_list/character_list_screen.dart,
   features/catalog/services/crushon_site_reader.dart (fetchSessionJson),
   features/chat/chat_actions_service.dart (importChatFromResult takes a summary), en.json.

2. Impersonation: the User Agency / User Name Accuracy helpers were injected into the prompt
   that writes the USER's next message, telling the model the opposite of the job. They are now
   lifted for impersonation only (PromptHelpers.forImpersonation, impersonationPromptSessionsProvider).

3. User Agency, stronger
   - Prompt rule rewritten: absolute, names {{user}}, covers speech, actions, feelings, body
     reactions, thoughts, second person ("you nod", "your heart races"), name-tagged quotes,
     and skipping ahead; end with the other character waiting.
   - Stop sequences: "\nName:", "\n*Name ", "\nName ", "\nUser:".
   - Post-processing (ReplyTrimmer.enforceUserAgency) now also catches second person, body
     reactions, "Name's eyes widen", the first name of a multi-word persona, and quoted words
     tagged with the user's name. A reply that OPENS with such a sentence now has it dropped
     instead of being left alone.

4. Guided swipe: reviewed end to end; no change needed.
