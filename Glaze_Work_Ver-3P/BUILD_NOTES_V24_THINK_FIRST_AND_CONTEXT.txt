Glaze v24: Think First moved to Reasoning + max-context lookup
===============================================================
Not compiled (no Flutter SDK here). Run: flutter pub get && flutter analyze && flutter test
New tests: test/model_context_lookup_test.dart, group in test/prompt_helpers_test.dart

1. Think First moved
   - Removed from Prompt Helpers (API settings and chat Tools sheet).
   - Now the last row of API settings > Reasoning section.
   - Only applies when "Request Native Reasoning" is OFF (native = request on and not
     omitted). While native is on the row is greyed out, shows why, and reads as off.
   - Enforced where the prompt is built, not just in the UI: PromptHelpers.buildText /
     toRuntimeBlocks take nativeReasoning; all three call sites pass it (normal prompt,
     prompt payload builder, Studio). Other helpers are unaffected.
   - The saved choice is kept (shared prompt-helper value), so turning native reasoning
     off again brings Think First back as the user left it. Effort slider still sets
     the thinking length.
   - MenuSwitchItem got an `enabled` flag for the greyed state.

2. Max context lookup (Settings > API > Check models)
   Audit: it only worked for Ollama, llama.cpp and /models lists that use Bearer auth.
   Gemini/Anthropic (own auth headers), LM Studio and most hosted providers returned
   "not reported". Now, in order: Ollama /api/show+/api/ps; llama.cpp /props; the
   /models list; LM Studio /api/v0/models (max + loaded); the provider's model list via
   the connection's own protocol/auth (OpenRouter, Gemini inputTokenLimit, Anthropic
   max_input_tokens, Mistral, Groq, Together, vLLM, GitHub...); finally a small
   built-in name table (GPT, o-series, Claude, Gemini, DeepSeek, Mistral large, Llama
   3.x), labelled "Built-in table (estimate)". Model ids match tolerantly (models/ prefix,
   :free tags, org/ prefix, case). Unknown models say so instead of guessing.
   Files: core/llm/model_context_lookup.dart (new), core/llm/model_probe.dart.
Not verified against live servers.
