Glaze provider sort / stats fixes - v7

1. JannyAI numbers
- JannyAI's public Meilisearch character index does not reliably expose the per-card chat/message figures shown on the character pages.
- Search results are now enriched from the JannyAI character page when those figures are missing.
- The page figures are parsed as chats (🗣️) and messages (💬), with the message figure used by the existing Glaze card badge first.
- Stats are cached in memory by character id so scrolling/reloading does not repeatedly fetch the same pages during the session.
- If Janny blocks a detail page, the catalog still works and the affected card simply has no badge rather than breaking the whole search.

2. Chub Latest
- Chub's current site uses `last_activity_at` for its Latest listing.
- Glaze previously used `id`, which produced a different set/order from the site's Latest page.
- Latest now requests `last_activity_at`, matching the site.

3. SpicyChat Popular vs Trending
- Trending remains SpicyChat's current `_text_match(buckets: 3):desc,num_messages_24h:desc` feed.
- Popular now uses lifetime `num_messages:desc` instead of `num_messages_24h:desc`.
- This prevents Popular and Trending from collapsing into the same list. The screenshots show the intended distinction: Trending is recent activity, while Popular contains the long-term high-message characters.
