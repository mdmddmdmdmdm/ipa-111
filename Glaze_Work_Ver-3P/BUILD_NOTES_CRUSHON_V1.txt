CrushOn.AI catalog provider — v1 foundation

What this drop adds
-------------------
A full third-party content provider for https://crushon.ai, wired the same way
as SpicyChat / Chub / Janitor:

  • Browse sorts matching the live site dropdown:
      Popular, Recent Hits, Trending, New, Daily Ranking,
      Editor's Choice, Following
  • Tag vocabulary (seeded from the site chips + live getSearchFilterTags)
  • Search (character.searchInfinite)
  • Daily Ranking date via CatalogFilters.window = "YYYY-MM-DD"
  • Favorites (account-scoped, needs sign-in)
  • Character import (best-effort; full definition needs session)
  • WebView sign-in sheet that captures CF clearance + auth cookies
  • Enum / catalog / favorites / sort-menu wiring

API notes
---------
CrushOn is Next.js + tRPC behind Cloudflare.
  GET  /api/trpc/character.getCharactersByTag   (sortTag=…)
  POST /api/trpc/character.searchInfinite
  GET  /api/trpc/character.getSearchFilterTags
  GET  /api/trpc/character.getFavoriteCharacters (auth)

Bare HTTP is challenged by CF. The login sheet must be opened once so
CrushOnWebSession can store cf_clearance + cookies; public sorts then work.

Following + favorites require a real signed-in session.

GIF / avatar URLs are passed through as CDN links; existing Image widgets
already render gif/webp.
